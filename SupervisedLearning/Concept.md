## Supervised Learning

- In a Supervised Machine Learning , we provide a large input data along with its results inorder for the machine to make pattern based on the data and predict outcomes for new set of data.

### EDA (Exploratory Data Analysis)

- EDA is a step before actual creation of the machine learning model.
- example looking at all values, data that can interrupt model, exploring what training can be done on models using the data, etc.

## Steps in EDA

1. Viewing the Data
2. Summery Statistics
3. Value count
4. Missing value analysis
5. Visualization

After EDA once we know about our dataset we'll move to the next step which is Data Cleaning

### Data Cleaning

1. Handling missing values

- if there are very few missing values in cols or rows than we can drop them
- if its a numerical data we can use -> Mean/Median
- if its a catergorical data (such as gender) we use -> Mode

2. Remove duplicates

- to detact and drop the repeated rows or cols

3. Fix data types

4. Handle inconsistant data

5. Fix logic
